# smart-city-issue-reporting-system
A Flask-based web application for reporting and managing civic issues.
## Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/itsmadhu875-code/smart-city-issue-reporting-system.git
   ```

2. Open the project folder:
   ```bash
   cd smart-city-issue-reporting-system
   ```

3. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

4. Set the Flask secret key using the `FLASK_SECRET_KEY` environment variable.

5. Run the application:
   ```bash
   python app.py
   ```

6. Open your browser and visit:
   `http://127.0.0.1:5000`

**Note:** The SQLite database is created locally by the application. Create the `static/uploads` folder if it does not already exist.
