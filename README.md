\# Smart City Issue Reporting and Management System



\## Project Overview

The Smart City Issue Reporting and Management System is a web-based application developed using Python and Flask. It allows citizens to report civic problems such as road damage, water leakage, and garbage issues. Administrators can manage complaints through a secure admin panel.



\## Technologies Used

\- Python

\- Flask

\- SQLite

\- HTML

\- CSS



\## Key Features

\- Online complaint registration

\- Optional image upload with complaint

\- Admin login and authentication

\- Admin dashboard with complaint statistics

\- Complaint status management (Pending/Resolved)

\- Search and filter complaints

\- SQLite database integration

\- CSRF protection and password hashing

\## Installation and Setup



1\. Clone the repository:

&#x20;  ```bash

&#x20;  git clone YOUR\_GITHUB\_REPOSITORY\_URL

&#x20;  ```



2\. Open the project folder:

&#x20;  ```bash

&#x20;  cd smart-city-issue-reporting-system

&#x20;  ```



3\. Install the required packages:

&#x20;  ```bash

&#x20;  pip install -r requirements.txt

&#x20;  ```



4\. Configure the required environment variables, including the Flask secret key and admin credentials, according to the application code.



5\. Run the application:

&#x20;  ```bash

&#x20;  python app.py

&#x20;  ```



6\. Open your browser and visit:

&#x20;  ```text

&#x20;  http://127.0.0.1:5000

&#x20;  ```
